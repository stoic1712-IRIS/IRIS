# Founder Full Access and Desktop Operation

**Status:** Implemented candidate

**Owner:** IRIS Core

## Contract

Founder Full access is one explicit, authenticated, session-bound grant for registered ordinary capabilities. It expires with the Founder session and is invalid after disable, logout, gateway restart, or Windows restart. Authorization, denial, expiry, and revocation enter the Core hash-linked audit.

Ordinary scope includes bounded repository inspection and editing, approved terminal commands, dependency materialization, verification and repair, candidate commit and non-force branch publication, pull-request and CI work, reviewed-head merge, history-preserving rollback, workspace cleanup, local runtime management, bounded desktop operation, approved zero-dollar capability acquisition, and local notification.

The grant never includes credential disclosure, spending, deployment, public or LAN exposure, repository or account administration, force-push or history rewrite, destructive data operations, elevation, or Phase 0 graduation.

## Desktop safety

Desktop execution binds an exact process and window target to a Core preview digest and one-time Founder approval. The fixed Windows UI Automation runner accepts only focus, invoke, non-secret text entry, selection, and bounded keypress actions. It rejects arbitrary coordinates, shell commands, wildcards, credential/payment/admin/elevation surfaces, stale approval, replay, and malformed provider output.

The Founder stop and Full-access emergency stop interrupt the live adapter and prevent late provider responses from reviving the session. Audit receipts contain metadata and digests, not raw screen or credential data.

## Rollback and non-graduation

Revocation stops new ordinary effects; disposable repository work uses history-preserving rollback and exact cleanup. This machinery is additive capability. It does not satisfy the separate Phase 0 Development Independence graduation gate.
