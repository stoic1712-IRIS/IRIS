# IRIS Applications

This directory is reserved for deployable IRIS processes and interfaces authorized by later capability waves.

No Layer 4 product belongs in this repository. Layer 4 applications remain independent repositories and products governed through IRIS-owned contracts.

## Visual Infrastructure Composer

`visual-composer` is the Wave 11 Founder interface for portable infrastructure blueprints. It is a replaceable React Flow client over the IRIS-owned `@stoic-iris/blueprints` contracts and compilers. The app can request approval but cannot approve, deploy, or make its visual state canonical by itself. It is infrastructure tooling, not a Layer 4 product.
